# dbt Workflow with Darrell

Darrell provides a convenient wrapper around dbt commands, allowing you to manage your dbt workflows efficiently. This guide will walk you through the process of initializing a dbt project, running models, testing, and generating documentation using Darrell.

## Initializing a dbt Project

To start a new dbt project, use the following command:

```bash
darrell models init
```

This command will initialize a new dbt project in your current directory, creating the necessary folder structure and configuration files.

## Running dbt Models

To run your dbt models, use the `run` command:

```bash
darrell models run
```

This will execute all your dbt models. If you want to run specific models, you can use the `--select` or `-s` option:

```bash
darrell models run --select model_name
```

Replace `model_name` with the name of the model you want to run. You can also use dbt's selection syntax to run multiple models.

## Testing dbt Models

To run tests on your dbt models, use the `test` command:

```bash
darrell models test
```

This will run all tests defined in your dbt project. Similar to the `run` command, you can use the `--select` or `-s` option to test specific models:

```bash
darrell models test --select model_name
```

## Generating dbt Documentation

To generate documentation for your dbt project, use the `docs` command:

```bash
darrell models docs
```

This command will generate the documentation for your dbt project, which you can then serve or publish as needed.

## Compiling dbt Models

If you want to compile your dbt models without running them, use the `compile` command:

```bash
darrell models compile
```

This is useful for checking the SQL that will be generated by your models without actually executing them against your data warehouse.

## Additional Commands

Darrell wraps these core dbt commands to provide a seamless experience when working with dbt projects. For more advanced usage or additional dbt commands not directly wrapped by Darrell, you may need to use the dbt CLI directly.

Remember that Darrell is designed to orchestrate both dbt and Evidence BI. For information on how to work with reports using Evidence BI through Darrell, refer to the Evidence BI documentation.

By using Darrell for your dbt workflows, you can streamline your data modeling process and integrate it smoothly with your reporting tools.
